Tampilan

Pilih palet warna (gaya Monet). Warna teks menyesuaikan otomatis supaya selalu terbaca: palet terang → teks hitam, palet gelap → teks putih. Berlaku untuk Menu, Beranda, Komposisi, History, dan Chat di perangkat ini.

Ketupat & Potong sudut memotong sudut kartu dan tombol, jadi cahaya kedip SPEC OUT / TARGET OUT hanya tampil di dalam kartu (warna tetap jelas).

Tombol Beranda

Centang = tampil di Beranda. Tombol ▲ ▼ mengatur urutan. Berlaku untuk tombol di atas dan kartu daftar di Beranda. Ikut tersinkron ke perangkat lain lewat mode Online (sama seperti data produk).
